# PeteCoach: Claude-Powered Elite Triathlon Coach, built into petehome

## Goal and race math

- Race: Supertri Chicago Olympic, Sunday **Aug 22, 2027**, 6:00 AM. 1500 m Monroe Harbor swim
  (wetsuit-likely), 40 km DuSable LSD / Lower Wacker / busway bike, 10 km lakefront run. **48 weeks
  from today.**
- Sub-3:00 split budget: swim 31–34 min (needs ~1:55–2:05/100 yd with wetsuit vs ~2:30 today —
  largest, cheapest gain); T1 6–8 min (long barefoot run, rehearse); bike 1:15–1:19 (19–20 mph, HR +
  speed based); T2 2–3 min; run 57–60 min (9:15–9:40/mi off the bike). Total ≈ 2:52–3:04. Thin
  buffer; live projection re-budgets monthly.
- Ordering: **knee health > consistency > sub-3.** Every plan mutation passes a deterministic
  guardrail layer.

## What petehome already gives us (verified in `C:\dev\petehome`)

- **Stack**: yarn-1 monorepo, `apps/web` Next.js 16 / React 19 / Tailwind 4 / shadcn on **Vercel
  Pro** (pete.sh), **Supabase Pro** Postgres (service-role writes, permissive anon RLS, no Supabase
  Auth), PM2 on the Windows home machine for `sync-worker.js` and HTTPS "hybrid mode", Vercel AI SDK
  6 + `@ai-sdk/anthropic`.
- **Ingestion**: `PeteTrainiOS` (iOS 26.1) and `PeteTrain` (watchOS 10) read HealthKit and POST to
  `/api/apple-health/{sync,workout,daily}` with a Bearer key. Already captures HR samples, running
  dynamics, cycling speed/cadence/power, GPS routes, events, effort, RHR/HRV(SDNN)/VO2max, body
  comp; swim support is in uncommitted work. **Not** Health Auto Export — the app is the pipe. Gaps:
  sleep stages/resp rate/wrist temp/SpO2 not queried; background delivery entitled but unused; watch
  sync aborts when the server ID check fails; API key hardcoded in source (`KeychainHelper.swift`).
- **Data**: `apple_health_workouts` + sample tables + `apple_health_daily_metrics` (a year of
  aggregates), `user_hr_zones_config`, `fitness_routine_versions` (your past plans, versioned),
  `exercise_weight_logs`, `ai_coach_*`, `assistant_user_memory`. **Retention risk**:
  `cleanup_all_old_records` deletes HR/cadence/pace samples after 90 days; coach chats after 30.
- **AI Coach**: Sonnet 4 (`claude-sonnet-4-20250514`), one giant context dump (~15–35k tokens/turn,
  no caching), 5 tools, readiness = weighted HRV/RHR/sleep/minutes/consistency,
  `proposeRoutineVersion` → draft version → apply. No cross-chat memory, no TSS/ACWR (heuristic
  ATL/CTL in `load-trend-card.tsx`, TRIMP per workout), no evals, no cost ledger. Unified assistant
  adds Haiku routing + KV memory digest.
- **UI to reuse**: `/fitness/activity` dashboard, workout detail + analytics,
  `dashboard-v3/live-signals` (readiness, load-trend, activity), activity rings, kanban week,
  routine editor, `useChat` chat surfaces, `weather.service` (NWS), Google Calendar service.

## Locked decisions

- **Transform, not bolt-on**: PeteCoach's periodized plan/session model becomes the single source of
  truth. `/fitness` becomes `/coach`; routine versions, workout_definitions, and the
  climber-physique AI Coach are migrated then retired after a compatibility window. Your _current_
  PT blocks (Morning Activation, Evening Armor) replace the stale "Morning Armor / Night Release"
  routines.
- **Apple Watch S12 is the only wearable**; Garmin retired (one-time Connect export for history).
  Coospo sensors pair to the watch. **PeteTrainiOS is the ingestion pipe**; Health Auto Export is
  not needed.
- **Runtime split**: chat/streaming and all HTTP APIs stay in `apps/web` on Vercel Pro
  (`maxDuration` raised to 300 s for tool loops); long/scheduled agent work runs in a new
  **`apps/coach-worker` under PM2** on the home machine with pg-boss on Supabase Postgres.
- **AI stack**: stay on Vercel AI SDK + `@ai-sdk/anthropic` (already in place); upgrade to current
  models (Opus 5 / Sonnet 5 / Haiku 4.5, IDs pinned in config), add Anthropic prompt caching via
  `providerOptions`, structured outputs via zod.
- **Strava API not used** (2026 policy bans AI use); Strava stays social.
