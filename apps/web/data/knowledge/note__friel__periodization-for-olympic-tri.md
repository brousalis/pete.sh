## Athlete constraints that shape the year

Priority order never inverts: **knee health → consistency → sub-3**. Bilateral medial cartilage wear, plica, hamstring inflammation, and Baker's cyst mean every block must leave room for Morning Activation and Evening Armor PT. Volume advances one variable at a time (frequency → duration → intensity).

## Macrocycle sketch (~48 weeks to race)

| Phase | Intent | Notes for this athlete |
| --- | --- | --- |
| Prep / return | Habit, PT compliance, aerobic base | Cap run impact; bias swim + bike |
| Base | Aerobic volume, strength foundation | Polarized ~80% easy; heavy strength 2×/week |
| Build | Race-specific intensity, bricks | Keep ACWR in range; one hard day quality |
| Peak | Sharpen, race sims | Protect knee; rehearsals > heroic volume |
| Taper | Freshness | Cut volume, keep a little intensity |

Exact week counts flex with symptom trends. A flare resets the current microcycle; it does not delete the season if caught early.

## Weekly anatomy (template)

- 2–3 swim (one CSS/technique focus)
- 2–3 bike (one Z2 long, optional sweet-spot later in build)
- 2–3 run (one quality only when cleared; prefer surface/soft when medial load is high)
- Strength 2× prep/base, 1× maintenance in-season (Rønnestad pattern)
- PT blocks daily as prescribed

## Intensity distribution

Default to **polarized / pyramidal**: most time genuinely easy, small dose genuinely hard, little chronic threshold junk. Threshold work appears in build as deliberate sessions, not accidental mid-zone grinding.

## Progression and injury guard

- Advance one lever per week when symptom scores allow.
- ACWR: treat rapid spikes (≥~1.5 relative to chronic) as a plan smell, not a badge.
- Same-day downgrades are allowed; calendar upgrades wait for approval.

## Race specificity

Late build includes: continuous swim at goal pace, bike at goal watts with Chicago course character (urban / busway / Wacker feel if possible), and controlled run-off-bike. Transitions are periodized skills, not afterthoughts.
